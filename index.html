Preguntas frecuentes

Algunas respuestas antes de comenzar.

¿Necesito saber programación? +
No. La idea de CreaTuWeb es facilitar la creación de sitios para personas que no tienen conocimientos técnicos.
¿Puedo usar mi celular? +
Sí. La interfaz está pensada para funcionar también desde dispositivos móviles.
¿Puedo cambiar las imágenes? +
Sí. Una versión completa del editor permitirá personalizar imágenes, textos, colores, botones y diferentes secciones.
¿Puedo conectar un dominio? +
La plataforma puede prepararse posteriormente para conectar dominios personalizados.
¿Puedo crear una tienda? +
Sí. Podemos incorporar posteriormente herramientas específicas para productos, catálogos y tiendas online.
